## 5. Improved weekly workflow (replace Gemini paste-fest)

### Daily (45–60 min)

1. Run **3 LinkedIn saves** only: Lane A remote, Lane B remote, Lane C remote (sort: past 24h).
2. Export to spreadsheet (`tracking/applications.csv`) — don’t paste 50 jobs into Gemini.
3. **Score each job 1–5** using rubric in `strategy/APPLICATION_SCORING.md` (2 min/job).
4. Apply only to **4+** scores; cap **5 quality apps/day**.

### 2x per week

- Local Santa Monica lanes (hybrid-friendly).
- Wellfound WF-2 + WF-1 (worldwide).
- 10 min: update tracker statuses.

### Weekly (Sunday)

- WF-3 gaming scan (optional).
- Review: applications sent, responses, which titles converted.
- Adjust one boolean if zero 4+ scores all week.

### Gemini / Cursor role

- **Stop:** pasting 50 job titles for “worth applying?”
- **Start:** paste **one JD + your resume** → tailored bullets + cover paragraph + “red flags”
