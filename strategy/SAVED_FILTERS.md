## “Jobs for you” vs saved searches — don’t abandon filters

| Source | Role in stack | Why |
|--------|---------------|-----|
| **Saved searches (Lanes A/B/C)** | **Primary** — 80% of discovery | You control booleans, boredom/fit, remote vs local |
| **Jobs for you** | **Supplement** — weekly 5 min skim | LinkedIn guesses from old clicks; can surface junk *or* gems |
| **Similar to applied** | **Supplement** — after a *good* apply | Useful when one JD was a 5/5 boredom score; run on that job’s page |

**Do not** replace saved filters with algorithm feeds. **Do** add steps 9–10 so you don’t miss niche titles booleans skip.

**Rule:** If it didn’t pass the rubric (`APPLICATION_SCORING.md`), don’t apply — even if LinkedIn recommended it.

## Remote + local — can you see both at once?

**No** on LinkedIn. **Remote** is a filter toggle — one saved search = remote only, another = no remote filter (on-site/hybrid/all in that radius).

| Setup | Remote filter | Location |
|--------|---------------|----------|
| **Remote US** save | ✅ Remote | United States |
| **Local hybrid** save | ❌ Remote off | Santa Monica, CA · **10 mi** · Workplace: **Hybrid** (not On-site only) |

**Hybrid vs On-site (local saves):** Use **Hybrid**, not **On-site** only — you want 1–2 day/week max, not 5× RTO. If LinkedIn lets you multi-select, check **Hybrid** + **Remote** for that radius (some “remote” jobs are tagged to LA). Skip **On-site**-only filter for daily use.

Run **both saves** for each lane (that’s why you have 6 LinkedIn saves). There is no single view that merges “remote US + SM hybrid” without noise.

**Daily:** remote saves only. **2×/week:** local saves.

## How to save on LinkedIn (one-time)

1. Jobs → search with boolean in keyword box  
2. Set **Location** + **Remote** (or not) + **Date posted: Past 24 hours** (when filtering session)  
3. **All filters** → Easy Apply (optional — prefer direct ATS when you see it)  
4. Click **Notify me** / **Save search** → name exactly as below

## LinkedIn booleans (6 saved searches)

Use in the Jobs search **keyword** field. **Caps:** `AND` `OR` `NOT`. **Quotes** = exact phrase.

**Remote US** — `LI-A-REMOTE` 

```
("Implementation Specialist" OR "Implementation Manager" OR "Onboarding Specialist" OR "Product Operations" OR "Technical Account Manager") AND ("SaaS" OR "software" OR "B2B") NOT ("Customer Service" OR "Help Desk" OR "Call Center" OR "Support Specialist" OR "Account Executive" OR "SDR")
```

## Quick reference: boolean syntax

| Syntax | Example |
|--------|---------|
| Exact phrase | `"Product Operations"` |
| OR | `("BizOps" OR "RevOps")` |
| AND | `(...) AND ("SaaS" OR "software")` |
| NOT | `NOT ("Accounting" OR "Bookkeeper")` |
| Group | Always wrap OR groups in `( )` |

**Avoid:** `NOT` without parentheses groups; more than ~6 OR terms (LinkedIn gets flaky).
